What it does

You talk. The rubric fills in.

  • Asks the question out loud and opens the mic without a click.
  • Scores the live transcript against the five steps, from partial results.
  • Interrupts a ramble when you talk past the limit without analysing anything.
  • Probes instead of grading when an answer is too thin to score.

Architecture

Audio goes straight to AssemblyAI. The server never touches it.

Browser

AudioWorklet converts mic float samples to PCM16 @ 16 kHz, 100 ms frames, and reads RMS for the live waveform.

→
WebSocket
raw PCM

AssemblyAI

Universal-Streaming universal-3-6-pro. Partial turns, final turns, word timestamps, end-of-turn detection.

←
transcript
+ timings

Server

tRPC only: mints single-use streaming tokens and grades answers. No audio is proxied, buffered or stored.

One process, no media server

Express serves the built client and answers two tRPC calls. Deployable anywhere Node runs.

The account key never ships

The browser requests a 60-second, single-use token per turn. The key stays server-side.

Engineering

Three bugs that would have killed a live demo

BUG 01

The cleanup that killed every session

The voice hook returned a new object each render, so the unmount effect re-ran constantly and tore down the live microphone. Effects now depend on stable callbacks.

BUG 02

Turn two onward had no audio

AudioWorklet registration is per AudioContext, not global. Our "already loaded" cache meant only the first interview turn could capture audio.

BUG 03

A watchdog that could never fire

The ramble timer depended on the transcript, so each new word restarted it. It now reads a ref, and interrupts long unstructured answers as designed.

Found by running the shipped AudioWorklet source against a stubbed Web Audio global in the test suite — 26 tests covering the rubric, delivery maths and audio resampling.

intervue07
Impact

Honest about what it is

  • Coaching at the moment of the mistake is the entire product. Feedback after the fact is what candidates already have.
  • Works without a microphone. Skip and typed-answer paths mean the grading engine is never gated on speech.
  • Degrades honestly. No LLM key falls back to a heuristic grader instead of pretending.
  • No audio is stored. Transcripts live in memory for the length of the session.
  • It's practice, and it says so. The interviewer never claims to be a recruiter or promises an outcome.
  • Next: two-way voice, resume-anchored questions, and a rubric that adapts to your role.
